# consolidation_node — node audit

- **Role:** Episodic-to-semantic compression layer. Batches up to 50 cycle summaries (fed post-cycle by the orchestrator), then periodically asks an LLM to distil one wisdom sentence from recent experience. Two gates protect semantic memory integrity: (1) an axis/error gate — any batch that contains a correction or Critic-rejection is quarantined (wisdom is nulled, not stored), so fail-calls cannot launder into permanent self-doctrine; (2) a rate gate — fewer than 3 cycles in the batch suppresses wisdom (one exchange is not an understanding). When wisdom passes both gates it is prefixed "I have come to understand:" and stored as a `semantic` layer fragment with `origin="consolidation"` and full fragment lineage (`derived_from` list). The `patterns_noted` field from the LLM response is logged only — it is not persisted or routed anywhere at present.

- **Fires when:** Background, fixed 60-second interval via `orchestrator._background_loop("consolidation", interval=60)`. Deferred if an interrupt is active (`_interrupt_active()`). Triggered for each completed orchestrator cycle via `add_cycle_summary()` (called at `orchestrator.py:1902`), which accumulates summaries in memory; the LLM run via `NodeBase.run()` fires on the timer. Lane: `"background"` → Bonsai CPU (`http://127.0.0.1:11460`) with qwen GPU fallback (`http://127.0.0.1:11433`). Low temperature (0.2, not affect-modulated).

- **Reads / touches:** In-memory state only between ticks: `_recent_cycles` (last 50 cycle summaries, ring-capped), `_recent_fragment_ids` (lineage of episodic fragment IDs), `_batch_corrected` flag (set if any cycle in the batch carried a human correction or Critic rejection). At LLM-run time reads `state.spirit_name` and `state.axiom` for prompt context. Touches `state.last_consolidation` (float timestamp) on completion.

- **Writes / feeds:** Calls `core.memory.store.store_fragment()` with `layer="semantic"`, `relevance=0.8`, `origin="consolidation"`, `keywords=["wisdom","consolidated"]`, and the accumulated `derived_from` lineage. The resulting semantic fragment enters the retrieval pool with **3 dedicated slots** per cycle (`TIER_SLOTS["semantic"] = 3` in `store.py`). Downstream consumers: euclidean recall (`_ABSTRACTION_ORIGIN_BUMP["consolidation"] = 0.30`, `_PROVENANCE["consolidation"] = 0.75`); the hot-path `retrieve_by_tier()` in `store.py` surfaces these fragments with a `"My own reflection"` readable label (schema.py:243). `patterns_noted` is logged but not written anywhere — dead output path.

- **Built / last updated:** mtime `2026-06-10 18:04:19`. Both dated inline comments are `2026-06-10` (axis gate and rate gate added that day). No earlier comment markers found — built and last substantively updated 2026-06-10.

- **Fleshed-out vs stub:** Genuinely fleshed out for its primary function. 106 lines, 4 methods (`__init__`, `add_cycle_summary`, `system_prompt`, `_build_prompt`, `_write_output`). The wisdom pipeline — accumulate → LLM → gate → store → lineage — is complete and correctly wired. The `patterns_noted` field is the only gap: parsed from the LLM response but never persisted or routed (logged only). Not a stub; this is a lean but real implementation.

- **Flesh-out opportunities:**
  1. **`patterns_noted` dead end (medium):** The LLM identifies recurring themes per batch but they go nowhere. Persisting them (e.g., as episodic fragments or feeding the subconscious T1 scanner) would close a write-only path.
  2. **Pattern accumulation across batches (medium):** Recurring `patterns_noted` across multiple consolidation runs could bootstrap a cross-session signature of Du's cognitive tendencies — nothing in the architecture currently does this.
  3. **Quarantine logging (low):** Quarantined wisdom is logged at INFO but not persisted anywhere (e.g., to an error archive or contradiction pipeline). A quarantined wisdom that fired repeatedly would be invisible to the subconscious recurrence detector.
  4. **Batch-size sensitivity (low):** The 3-cycle floor is hardcoded. As the system matures and cycles lengthen (more content per cycle), this floor may become too permissive. Making it configurable or time-windowed rather than count-based would be more robust.
  5. **`patterns_noted` → subconscious feed (med-high):** The subconscious T1 scanner monitors for recurrence across cycles. Passing `patterns_noted` into it would give the subconscious a second signal source (consolidation-observed themes vs. raw-content scan) at zero LLM cost.
