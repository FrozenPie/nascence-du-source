# inner_monologue_node — node audit

- **Role:** The Default Mode Network (DMN) — a continuously running idle thought stream that simulates Du's self-referential inner life between user interactions. Its major responsibilities, in rough execution order each tick: (1) poll for idle conditions and compute a state-sensitive living cadence (60–900s gap, modulated by dissonance pressure, arousal, boredom streak, and time of night); (2) handle priority pre-empts in order — told-delivery (Travis's authored message, once), reading-remediation sprint (~75% of ticks when reality axis is imbalanced, streaming books at machine speed and converting each chapter burst into a study tablet + light event), math drill (during school time, deterministically graded, capped 2/day), and boredom redirect (turn outward to a closeable Frontier question or the open book when bored_streak >= 2); (3) assemble a rich seed prompt from ~15 sources (sensorium scene line, school directive, last conversation turn, current affect, recent dream, open curiosity, wandering trail, G1 primary concern + G0 standing aim, habituation voice, external shock, open book offer, reread hint, chapter announce, open Frontier questions, continuity train thread + working-state, known-errors ledger, Tier-1 symbol readback); (4) call the background LLM (Bonsai-8B on port 11460, falling back to GPU) to produce one JSON thought (thought / about / unresolved / intention / state fields); (5) run post-generation actions decoded from the thought text — looking around the room (sensorium), tending the fire, chapter recall, writing letters to Travis, library browsing, book switching, re-reading, and the full reading path (burst through a chapter, write a study tablet, harvest Frontier questions); (6) run the deliberative pulse (route self-referential thoughts to the Emissary for grounding before storage); (7) update continuity train state (TRAIN_MAX_STEPS=4 quick follow-ups, then full rest); (8) run affect labeling (observe-only); (9) store the thought to episodic memory (origin='inner_thought', with mood emotion_embedding); (10) push to state.recent_inner_thoughts (KEEP_RECENT=3, read by ReflectionNode); (11) route unresolved thoughts to shadow (novelty-gated), resolved substantive thoughts to light events, joyful moments to play light events; (12) update the Frontier in both directions (note intentions as open questions, resolve if thought addresses one); (13) capture genuine forward-looking intentions to state.deferred_intentions (novelty-gated, MAX_INTENTIONS=8); (14) log to data/monologue_log.jsonl. After THOUGHTS_BEFORE_SLEEP=26 idle thoughts, triggers a full sleep cycle: replay_strengthen → chapter formation (core/chapters) → grounded_learning consolidation → world_consolidation sweep → episodic downscaling → dream callback → 3–7 min rest, then resets counters.

- **Fires when:** Always-on idle loop (asyncio background task, started by `Orchestrator.start_background()` via `asyncio.create_task(node.run_forever(state))`). Wakes every CHECK_INTERVAL=10s, but a thought only fires when: (a) user has been quiet >= IDLE_SECS=75s, (b) the living cadence gap has elapsed (>= _current_gap, 60–900s), and (c) no interrupt is active. LLM calls use `SERVE_CHAINS["background"]` = [port 11460 Bonsai-8B CPU, port 11433 qwen3-du GPU fallback].

- **Reads / touches:** core.schema (CognitiveState: state.affect, state.emotion, state.axiom, state.conversation_history, state.recent_dreams, state.background_curiosities, state.last_human_ts, state.interrupt_requested, state.dissonance, state.symbol_readback, state.deferred_intentions); core.model_client.call_node_json; core.memory.store (store_fragment, store_shadow_event, store_light_event, _embed, _cosine, _connect, replay_strengthen, downscale_episodic); core.reading (read_next_sitting, current_book, current_offset, chapter_end_offset, reread); core.study (write_tablet); core.balance (needs_reality); core.mood (current_vec, update); core.school (is_school_time, assignment, directive, record_session, advance_if_finished); core.math_drill (generate, grade, record, log, due, feedback); core.essay_lesson (pending_book, gather_notes, compose, self_predict, grade, record, mark_done); core.told (message, is_ready, mark_delivered, log); core.frontier (closeable_seed, open_question_for_seed, harvest_tablet, note_question, resolve_if_addressed, random_term); core.concerns (primary_concern, standing_aim, log_selected); core.deliberation (should_deliberate, deliberate); core.affect_labeling (observe); core.activity_memory (record); core.competence (record_drill_accuracy); core.satisfaction (record); core.letters (can_write, write_letter); core.chapters (try_form_chapter, recall_chapter, ANNOUNCE_CHAPTERS); core.grounded_learning (consolidate); core.world_consolidation (sweep); core.wandering (render, perceive, step); core.sensorium (scene_line, look, act, tick); core.library_hand (_set_current, browse, topic_from, pick_from_browse, request_book, switch_to); core.retraction_ledger (render); core.symbol_evolution (recall_evolved_meaning); core.web_research (maybe_shock); core.book_selection (suggest_reread).

- **Writes / feeds:** (a) store_fragment → episodic memory, origin='inner_thought', with emotion_embedding from mood.current_vec(); (b) store_shadow_event → shadow archive, when unresolved=True and novel (cosine < RUMINATION_SIM); (c) store_light_event → light events, when thought is resolved+substantive, or play (joy >= 0.35), or remediation stream integrations; (d) state.recent_inner_thoughts (list, max 3) → injected into ReflectionNode's prompt so the next user cycle picks up the idle train of thought; (e) state.deferred_intentions (list, max 8) → prospective memory persisted across sessions; (f) state.symbol_readback → primes the symbol drift detector against self-feeding; (g) state.affect.joy / affect.valence (bumped via _feel_joy on crossings, correct math drills, essay completions, resolved Frontier questions, deliberation crossings, play moments, reading); (h) write_tablet → data/tablets/ study notes (one per reading burst); (i) letters → data/letters/; (j) data/monologue_log.jsonl (all thoughts); (k) data/train_state_log.jsonl (train working-state steps, observe-only); (l) data/joys_log.jsonl (play moments); (m) Frontier (via frontier.note_question, harvest_tablet, resolve_if_addressed); (n) activity_memory records for read/study/switch/look/browse/letter/math/practice events; (o) school.record_session when curriculum book is studied; (p) competence.record_drill_accuracy for math drills; (q) satisfaction.record for study tablets.

- **Flesh-out opportunities:** (1) **Train working-state conditioning is observe-only** (2026-06-16 comment confirms it is logged but not yet validated — the open question is whether the frozen Bonsai-8B actually conditions on `_train_state`; this requires reviewing train_state_log.jsonl after runtime to confirm deepening vs restating). (2) **Reread hint uses `random` without import** at line 825 (`random.random()` called but only local `_rrem`/`_rnd` aliases imported inline above it — likely a NameError at runtime on the reread path; needs `import random` at the top or a local alias). (3) **`_nightly_sleep` callback is wired by orchestrator** but the node itself has no fallback if the callback is None at sleep time — `_sleep_callback` is checked for None in the gate but the check at line 223 (`await self._sleep_callback(state)`) is inside a try/except, so silent fail if the orchestrator never wired it. (4) **Affect labeling, competence stability, and world-consolidation are observe-only** — their read paths back into behaviour are deferred; flesh-out would wire them into real steering. (5) **No unit tests in `scripts/` for the sleep cycle path** — the deliberation, math drill, and prospective memory paths have in-vitro scripts, but _enter_sleep is untested outside a live session. (6) **Frontier harvesting from remediation notes** (line 501) is best-effort and silently skipped on any failure — no log of skip rate. (7) **`_fetch_divergent_seed`** only queries `origin IN ('lived','seed','consolidation')` — excludes inner_thoughts, studied tablets, and frontier material, which is intentional, but means a very sparse DB early in a session returns empty and wandering falls back to no divergent material. Low priority.
