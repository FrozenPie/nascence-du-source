# emotion_node — node audit

- **Role:** Instantaneous per-cycle emotional appraisal of the current percept. Reads `state.perception` (or falls back to `state.raw_input`) plus any pre-cognitive `state.affective_prior` (C.2 amygdala gate set by the orchestrator before this node fires), and emits an `EmotionOutput` on `state.emotion` — a full 8-dimensional affect profile (Ekman-6: joy/fear/anger/trust/surprise/disgust; plus Russell-circumplex valence/arousal; plus `primary` label). This is the instantaneous "what am I feeling right now" reading; it is distinct from `state.affect` (AffectState), which is the *carried* cross-cycle running average that the orchestrator integrates from this output after the node returns.

- **Fires when:** Hot-user-cycle, Wave 2 (concurrent with salience and memory_router). `NODE_REGISTRY["emotion"] = {"lane": "hot", "fires": "after_perception"}`. In the orchestrator at line 526–529: `await asyncio.gather(self.nodes["emotion"].run(...), self.nodes["salience"].run(...), self.nodes["memory_router"].run(...))` — fires on every non-habituated cycle (both `input_type="human"` and `input_type="internal"`). Also fires on background/internal autonomous cycles that pass the thalamic gate. Does NOT fire during background-lane timer nodes (consolidation, curiosity) — those run separately and do not call this node. LLM lane: **"hot"** → SERVE_CHAINS primary `http://127.0.0.1:11433` (ollama qwen3-du, 1080 Ti GPU), failover to `http://127.0.0.1:11460` (CPU Bonsai).

- **Reads / touches:**
  - `state.perception` — event_type, summary, entities (Wave-1 output, available before Wave-2 fires)
  - `state.raw_input` — fallback if perception is None
  - `state.affective_prior` (AffectivePrior, C.2) — optional pre-cognitive resonance note surfaced in the prompt as "BEFORE YOU APPRAISE"; set by `orchestrator._emotional_pre_retrieval()` before Wave-2. Read-only in this node.
  - Inherits `NodeBase` temperature path: `base_temperature = 0.2`, `affect_modulated` NOT set (defaults False) — correct by design, perception/classification nodes must stay stable.

- **Writes / feeds:** Sets `state.emotion: EmotionOutput` (all 8 dimensions + primary). Downstream consumers (all confirmed by grep):
  - **orchestrator** immediately after Wave-2: `state.affect.integrate(state.emotion)` — the homeostatic loop that updates the carried AffectState; `_mood.observe(state.emotion)` → `state.emotion_vec` (384-dim MiniLM embedding for affective retrieval); `state.emotion.arousal` → affect-importance score for episodic persistence (line 1889); `state.emotion.primary` → tagged onto shadow_events, light_events, and the cycle summary stored to episodic memory.
  - **reflection_node** (`_build_prompt` line 157–159): injects `e.primary / e.valence / e.arousal` as "Emotional state" context; reflection's schema has `emotionally_aligned` field gated on this.
  - **recall_node** (`_build_prompt` line 101–102): injects `e.primary` as "Current emotion" for reconstruction colouring.
  - **episodic_buffer_node** (`_build_prompt` line 101–102): injects full valence/arousal/primary as part of the bound scene.
  - **executive_node** (`_build_prompt` line 157–161): injects `e.primary / e.valence / e.arousal` into the synthesis context.
  - **inner_monologue_node** (lines 1478, 1498, 1531): passes `emotion_primary` to shadow/light event stores during idle thought cycles.
  - **_persist_cycle**: appends `Emotion: {primary} (valence=...)` to the stored episodic fragment summary.
  - **_log_affect**: writes `emotion.primary / valence / arousal` to `data/affect_log.jsonl` every cycle.
  - **run_nascence.py** (line 459–461): prints instantaneous emotion to REPL HUD.

- **Fleshed-out vs stub:** 56 lines total. 3 meaningful methods: `system_prompt` (property), `_build_prompt`, `_write_output`. Method count: 3 (all required by NodeBase contract). Verdict: **thin but complete for its scope**. It is not a stub — the C.2 affective-prior path is a genuine architectural integration point. But it is the thinnest generative node in the hot path: no internal logic beyond prompt-building and output-unpacking. The richness lives downstream (AffectState.integrate, mood.observe, affect-importance scoring) rather than inside this node. No TODOs, no dead code, no Phase-0 comments. `affect_modulated = False` (inherited default) is correct and intentional. The `base_temperature = 0.2` inherited from NodeBase is also correct for a classification node.

- **Flesh-out opportunities:**
  1. **Carry context from prior cycles** (medium priority): the node currently has no access to `state.affect` (the carried running average). A sentence like "Current carried mood: valence=+0.31, arousal=0.62" in the prompt would let the LLM appraise this cycle's percept in light of what is already being felt — the difference between a surprise arriving into a calm baseline vs. one arriving into already-elevated fear. The schema and AffectState already exist; it is one line in `_build_prompt`.
  2. **Somatic context** (low priority): `state.somatic` (metabolic energy/fatigue/tension) is available on state but not surfaced to this node. A physically exhausted entity should have a different emotional baseline. Currently fatigue only modulates generative-node temperatures, not the emotion appraisal itself.
  3. **Conversation-history tone context** (low priority): a single sentence summarising the emotional arc of the last 2–3 exchanges (already in `state.conversation_history`) could ground the appraisal in relational continuity rather than pure percept-level classification.
  4. **`affect_modulated` option** (low priority, design question): EmotionNode is explicitly not affect-modulated (correct — classification must be stable). But the current design means the node is entirely blind to what it previously read. If affect-state feedback is added via the prompt (opportunity 1), that achieves the same continuity effect without temperature-sampling instability.
  5. **No inject of `state.salience`**: salience fires concurrently (Wave-2) so it is unavailable. If the pipeline were re-ordered to fire emotion after salience, the focus/urgency signal could sharpen emotional appraisal. This is an architectural trade-off, not a bug.
