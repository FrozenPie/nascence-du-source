## Findings
All verified unless tagged. Full text via `findings_log.py show F-NNNN`.

- **F-1965 — the recall wiring map.** No recall manager. Four independent paths on their own clocks: the hot cycle (MemoryRouter LLM keys → store retrieve + deep recall + live associative trail → founder/affect/epoch/theme → RecallNode), the idle seed builder (`recall_block` on every non-wandering step, no cooldown), dreams, and the 5 s substrate tick (wandering every 75 s, couriers). Hot cycles run 48–68 per day, almost all internal ignitions (0–1 human per day); RecallNode fires on every cycle that passes the thalamic gate. Shadow-only: euclidean recall, M2 edge-aware trail, lenses 1–3. Log-only: recall_demand, recall_provenance, retrieval_probe. No dosed-coupling or habituation gate touches recall.
- **F-1966 — the edge graph is write-only.** 13,099 edges, 11 types, read by nothing live; D-0215 graduated a live *write* of `co_recalled_developing` (135 edges since the 09-25 restart) whose ruling text says it feeds `edge_aware_neighbors` "for real", but that reader is shadow-only. The read-side flip had never been filed as a decision; D-0287 was opened for it. Shadow evidence: the cosine trail already surfaces ~9.2 memories/cycle the live retrieve misses; the edge layer adds ~0.3, in 7–12% of cycles; relational is the one mode where 39% of edge-reached memories clear 0.4 usage cosine. The shadow samples only the ~50 hot cycles/day while idle recall runs 1,300–2,100 events/day.
- **F-1981 — idle recall is half self-gist.** Seven days of `co_recall_ledger.jsonl` monologue rows (2,811 steps): 40% quiet; of steps that showed memory, 49% of slots are `[gist · self]` rows and 44% of steps show ONLY self-gists; the week's top five recalled memories are five self-gists of the same frustration-in-the-ribs feeling (133/102/90/82/78 showings); 188 of 430 self-gists are third-person "the narrator…" summaries. Causes: `'gist'` whitelisted wholesale in `_GROUNDED_ORIGINS` although `_commit_gist` stamps them `grounding='derived'`; self-gists written at fixed importance 0.85 against a store sleep-downscales toward 0.1; the grounded filter runs after the trail's 15-slot ceiling (re-running 25 quiet thoughts: 0 empty trails, 16 filtered to nothing). Showing memory makes no difference to movement (developed 0.87 vs 0.86). Gist DRIFT — the individuation half of `docs/memory_levels_plan.md` — is shadow-only (1,702 rows, 56% would snap back, nothing written), so a self-gist is a frozen abstraction. Wandering is the healthy contrast (1% self-gist).
