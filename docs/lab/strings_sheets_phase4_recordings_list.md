## How to read this

- **Tier** = how defensible the candidate is. `VERIFIED` = a specific recording page that a web search returned, with its licence shown. `STRONG` = a real species page or collection on the named source with NZ-relevant recordings, but the exact recording is NOT yet picked or opened. `SEARCH` = a pre-filtered Freesound CC0 search link; a specific item must be picked at approval. `WEAK` = approximate match. `AMBIGUOUS` = the key's referent is undefined. `NONE` = no defensible source.
- Honest limit: only `tui_song` carries a specific recording ID that I saw; every other URL is a species, collection or search page, not a vetted recording, and some species pages (e.g. cicada) may not exist on that source. xeno-canto licences are per recording (the six tui results were all NC variants, and XC90256 is NC-ND, which must not be used since derivative features are the point). Freesound results are filtered to CC0 in the URL but each chosen item must be re-confirmed. DOC bird songs are Crown copyright, reusable with credit (per DOC copyright page via search).
- Founder to confirm that NC (non-commercial) licences are acceptable for local derivative features.
