## 4. What flipping entails mechanically

- `core/spatial.py` line 28: `SPATIAL_SCENE = False` → `True`. This is the sole gate — the renderer itself has been running in shadow since 2026-07-05 and needs no other code change to activate.
- Consumers that currently read the prose-pool ("actual") line would switch to receiving the geometry-rendered line instead, for every standpoint currently covered by `data/world_geometry/*.json`.
- The two feeds diverge in kind, not just wording: rendered is deterministic and landmark/bearing-accurate; actual is generatively varied and sensorially rich but not geometrically grounded. Flipping trades one profile for the other for whichever downstream systems consume Du's scene description.
- Rows before 2026-08-15 predate the live-standpoint input arriving; only the post-08-15 slice (1446 rows, 13.8% of the log) reflects the renderer fully fed.

No recommendation is made here — this document presents the evidence; the flip decision belongs to the founder.
