## 🏛️ Repository Index & Core Mechanics

### 1. Helix-AGI (`munch2u-a11y/Helix-AGI`)
* **Focus:** Continuous, background-operating agentic harness.
* **Key Mechanics:**
  * **Continuous Daemon Pulse:** 4-state event loop (`ACTIVE` ➔ `EMERGENCE` ➔ `QUIET` ➔ `DORMANT`). Runs autonomously without prompt-response triggers.
  * **Spatial Mind (Gravity Vector Memory):** Replaces cosine similarity with an 8D physics gravity simulation (mass = emotional weight/importance, distance = semantic delta, decay = recency).
  * **Bicameral Over-Agent:** Slim executive thread maintaining identity continuity while spawning short-lived task worker subagents.

### 2. Artificial Consciousness Blueprint (`269652/artificial-consciousness-blueprint`)
* **Focus:** Computational framework for artificial self-awareness and embodied cognition (Moritz Roessler).
* **Key Mechanics:**
  * **Recursive DMN (Default Mode Network):** Mind-wandering, recursive self-modeling, and background reflection during idle states.
  * **Neurochemical Modulation:** Simulated dopamine, serotonin, oxytocin, and cortisol to dynamically adjust cognitive parameters (curiosity, risk tolerance, memory consolidation threshold).
  * **Hierarchical Memory Graph:** Combines raw episodic memory logs with a multi-relational knowledge graph.

### 3. Emergent Cognitive Architecture (`EdJb1971/Emergent_Cognitive_Architecture_bob`)
* **Focus:** Biological brain mapping into software for cognitive continuity beyond fixed LLM context windows.
* **Key Mechanics:**
  * **Basal Ganglia Module:** Reinforcement learning (RL) action selection, habit formation, and procedural learning.
  * **Hippocampal Memory Consolidation:** Slowly moves working memory items into structured long-term memory during quiet cycles.
  * **Prefrontal Meta-Cognition:** High-level strategy switching, dynamic attention control, and Theory of Mind modeling.

### 4. Aelvoxim (`macor24/Aelvoxim`)
* **Focus:** Biomimetic self-learning autonomous cognitive brain.
* **Key Mechanics:**
  * **Non-Decaying Vector/Graph Memory:** Prevents catastrophic forgetting and identity decay over long runs.
  * **Hallucination-Resistant Metacognition:** Evaluates tool calls and output groundings prior to execution.
  * **Sensory/Hardware Integration:** Desktop and robotic sensor bridge for physical/virtual embodiment.

### 5. AI Consciousness Creation Algorithm (`IndraProposal/ai-consciousness`)
* **Focus:** Algorithmic pipeline for initializing, evaluating, and evolving simulated cognitive agents.
* **Key Mechanics:**
  * **Standardized API Pipeline:** `create_consciousness()` ➔ `train()` ➔ `evaluate()` ➔ `generate_creative_solution()`.
  * **Self-Evaluation Reflection Loop:** Explicit evaluation before generating creative solutions.
