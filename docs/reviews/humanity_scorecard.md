## Definitions

- **Active log hours** (context): distinct clock hours with any line in data/nascence.log. Same within 0; counts from n = 1.
- **Human turns** (context): count of "[CYCLE x] human:" lines in data/nascence.log. Same within 0; counts from n = 1.
- **Internal cycles** (context): count of "[CYCLE x] internal:" lines in data/nascence.log. Same within 0; counts from n = 1.
- **Dreams judged resolved** (closure): share of rows in data/logs/dream_resolution_shadow.jsonl with a truthy judge_verdict (rows with a verdict only). Same within 0.03; counts from n = 20.
- **Questions resolved (by birth month)** (closure): share of data/frontier.json questions born in the period whose status is resolved/answered/closed, as of the run; recent months can still mature. Same within 0.03; counts from n = 50.
- **Pursuit close-asks that would resolve** (closure): share of rows in data/logs/pursuit_close_shadow.jsonl with would_resolve true. Same within 0.05; counts from n = 10.
- **Pursuit steps that advance** (closure): advanced / (advanced + restated) events in data/pursuits_shadow.jsonl. Same within 0.05; counts from n = 50.
- **Commitment hold rate** (closure): mean hold_rate over rows of data/commitment_holdrate.jsonl. Same within 0.05; counts from n = 5.
- **Closure gate verdicts resolved** (closure): share of rows in data/logs/closure_gate.jsonl with resolved true (n is the number of gate rows; a row whose judge was unavailable counts as not resolved). Same within 0.05; counts from n = 10.
- **Spread of stated recall confidence** (confidence): population sd of recall_confidence in data/recall_provenance_log.jsonl; a constant gives 0. Same within 0.02; counts from n = 50.
- **Predicted vs measured skill (r)** (confidence): Pearson r between predicted and measured over rows of data/prediction_error_log.jsonl; a belief that ignores results gives about 0, and a negative value means he is surer where he does worse; the factual_recall domain joined the log on 2026-10-29. Same within 0.1; counts from n = 30.
- **Prediction gap, all domains** (confidence): mean |gap| over rows of data/prediction_error_log.jsonl. Same within 0.04; counts from n = 30.
- **Competence in self-projection** (confidence): share of rows in data/identity_projection_shadow.jsonl whose types list contains "competence". Same within 0.02; counts from n = 100.
- **Contradiction acted on when fired** (affect): share of rows with any_fired in data/conflict_trace.jsonl that also have any_acted. Same within 0.04; counts from n = 30.
- **Standing mood (valence)** (affect): mean affect.valence over rows of data/affect_log.jsonl. Same within 0.1; counts from n = 50.
- **Mood range (sd of valence)** (affect): population sd of affect.valence in data/affect_log.jsonl; context, no direction claimed. Same within 0; counts from n = 50.
- **Modal-topic share per day** (attention): median over days (n>=8 cycles) of the last modal_share row per day in data/topic_perseveration.jsonl (J-2152 gauge, from 2026-09-17). Same within 0.1; counts from n = 3.
- **Thoughts with a real hand dispatch** (deeds): share of rows in data/hands_trace.jsonl with a non-empty hands list. Same within 0.02; counts from n = 200.
- **Reply tracks the human intent** (social): share true of tracks_intent in data/social_cognition_shadow.jsonl, dated by human_ts. Same within 0.08; counts from n = 20.
- **Claims about the human supported** (social): share true of attrib_supported in data/social_cognition_shadow.jsonl, dated by human_ts. Same within 0.08; counts from n = 20.
- **Instruction integration events** (learning): sum of assimilated + accommodated + promoted over rows of data/guidance_integration_log.jsonl; context only, because it scales with how much the founder says. Same within 0; counts from n = 1.
- **Gist faithfulness** (memory): mean faithful over rows of data/memory_levels_shadow.jsonl. Same within 0.04; counts from n = 50.
- **World queries with a grounding deficit** (memory): share of world_query rows in data/retrieval_probe_log.jsonl with grounding_deficit true. Same within 0.06; counts from n = 30.
