# Strings and Sheets: by-ear listening sheet for the large-shift re-seed keys (J-2402, 2026-10-19)

Prepared for Travis. Job J-2402 (from F-3101, J-2395, D-0476). Source of the numbers: `docs/lab/strings_sheets_phase4_reseed_2026-10-18.md` section 4. Source of the files: `docs/lab/strings_sheets_phase4_manifest.md`. Nobody has listened to these files yet; every relevance judgement so far came from titles, search rank and signal analysis.

**Scope.** 41 axis values across 25 keys moved by 0.40 or more (of 115 applied re-seeded values). Each new seed was fitted to the one recording below, so a wrong file makes a wrong seed.

**How to answer.** Per key, one of: `right file` (keep the re-seed), `wrong file` (revert that key to its old seed and re-pick the file under D-0377, then re-measure), `unsure`. Put the answer in the `Answer:` line.

**Notes on listening.**
- The measured values come from the *gated* loud seconds of the file (J-2383), not the quiet parts, so judge the loud passages. The 5 s clips are a convenience sample (the manifest window when one exists, otherwise the middle of the file); the full file is the real test.
- Freesound files are ~128 kbps HQ previews (mp3); xeno-canto files are original uploads.
- "Old" is the previous `_SOUNDS` seed; "new" is the proposed re-seed; delta is new minus old.
- Clips are scratch copies in `data/_listen_J2402/` (mono, 96 kbps); delete the folder when done.
