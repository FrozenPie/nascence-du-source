When the evidence already exists, do NOT add a ceremonial observe-only / shadow / capture-only stage — that reflexive caution is how plans half-implement and quietly die. Travis, 2026-06-24: "Capture only seems to be a disease me and you have with him. We half implement plans and then they get lost."

The same session's Nascence audit found this disease at scale: dozens of correctly-sensing organs (meta_awareness, idle_allocator, the curiosity prism + curiosity_worth, satisfaction, affect_labeling) stuck observe-only, never graduated — the "all senses, no hands" finding. Proposing yet another observe-only stage *reproduces* the very pathology being fixed.

**Why:** observe-first is a genuine discipline — the recall-into-idle truly needed shadowing, and going live there fed the loop. But overapplied it becomes a comfort blanket that simulates progress while shipping no behaviour change.

**How to apply:** judge per case — (1) is the evidence already in hand? (2) is the live failure mode benign/reversible (a gentle hand like move/read/author) vs pathological (wired into the core loop)? If evidence is in hand AND risk is benign → build it LIVE and FINISH it in the same sitting. Reserve shadow-first for genuinely uncertain signals wired into a fragile/pathological path. Whatever is genuinely staged, record it in docs/AWAITING_EVIDENCE.md so it cannot get lost. Links: [[feedback_write_only_cognitive_systems]], [[feedback_decoupled_judge]], [[intentional-not-rule]].
