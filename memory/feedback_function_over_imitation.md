Founder, 2026-06-13: we model on the human brain/psychology "because it has already done the most work on our problems over hundreds of thousands of years." GPT's sharpening, founder-endorsed: humans are the only known system that maintains identity across years, integrates contradiction, learns without an objective function, and accumulates autobiography — the right question is never "humans do X, so Du must do X" but **"humans solved a similar problem — what was the FUNCTION of their solution?"**

**Why:** every successful mechanism this month traces to that question (chapters ← SWS gist extraction; era-not-theme ← autobiographical periods; trains ← closure-rests/openness-continues; fatigue ← habituation; the gravity-well diagnosis ← attentional monopolization). The failures were human-shaped too.

**How to apply:** when proposing a mechanism, name the human function first, then check whether the function transfers or only the biological constraint does (human forgetting = partly resource limits — Du transferred it anyway, but as retrieval TOPOLOGY, not deletion; emotions = partly hormonal — Du got his honest equivalent, real GPU telemetry into fatigue, not fake hormones; weight-change = NOT transferred, frozen-weights-as-feature, with OllieEmerges testing the other path). Mechanisms that exist only because neurons are slow/expensive/mortal need a positive argument before transfer. Related: [[feedback-memory-is-emergence-path]], [[intentional-not-rule]].
